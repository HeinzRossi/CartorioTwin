# S0-T04 — Fundação da solução .NET 10

**Estado:** Concluída

**Início:** 15/10/2026

**Baseline documental:** 1.2.0

## Rastreabilidade

- Requisitos: RF-001, RF-002, RF-012 e RF-013, somente quanto à fundação técnica futura.
- Requisitos não funcionais: RNF-008, RNF-010, RNF-011 e RNF-016.
- ADRs seguidos: ADR-001, ADR-003, ADR-008 e ADR-011.
- Nenhum novo ADR previsto: esta task materializa decisões já registradas.

## Critérios de teste

- Restaurar dependências com lock files.
- Compilar `CartorioTwin.sln` em `Release` no Windows com .NET 10.
- Descobrir e executar os quatro projetos xUnit.
- Confirmar que `CartorioTwin.Domain` não referencia WPF, EF, HTTP ou Infrastructure.
- Executar CI Windows e varredura de segredos no GitHub.
- Confirmar visibilidade autorizada do repositório e proteção da branch `main`.

## Arquivos e áreas impactadas

- Configuração raiz de .NET, NuGet, editor e Git.
- `src/`: oito projetos definidos em `02_ARCHITECTURE.md`.
- `tests/`: quatro projetos xUnit.
- `.github/workflows/`: build, testes e varredura de segredos.
- README raiz e este registro de execução.

## Riscos

- Token atual do GitHub CLI inválido pode bloquear criação/configuração remota.
- Restore depende de acesso ao NuGet e pode exigir autorização de rede.
- WPF precisa compilar em Windows; validação local e CI usarão agentes Windows.
- Warnings tratados como erros podem revelar incompatibilidades dos templates.
- A publicação torna o código acessível publicamente; essa mudança foi autorizada explicitamente para viabilizar a proteção de branch no plano atual da conta.

## Evidências de execução

- `dotnet restore CartorioTwin.sln`: concluído; 12 projetos restaurados e 12 lock files gerados.
- `dotnet restore CartorioTwin.sln --locked-mode`: concluído.
- `dotnet build CartorioTwin.sln -c Release --no-restore`: concluído em Windows x64; 0 avisos e 0 erros.
- `dotnet test CartorioTwin.sln -c Release --no-build`: quatro assemblies descobertos; 4 testes aprovados, 0 falhas e 0 ignorados.
- `dotnet list src/CartorioTwin.Domain/CartorioTwin.Domain.csproj reference`: nenhuma referência projeto-a-projeto.
- `dotnet list src/CartorioTwin.Domain/CartorioTwin.Domain.csproj package`: nenhum pacote.
- `dotnet --info`: confirmou SDK 10.0.401, host 10.0.12 e Windows Desktop Runtime 10.0.12, mas retornou código 1 ao consultar o Service Control Manager por falta de privilégio. Restore, build e testes não foram afetados.

## Evidências GitHub e CI

- Repositório criado como privado e posteriormente tornado público mediante autorização explícita: `https://github.com/HeinzRossi/CartorioTwin`.
- CI Windows concluiu restore bloqueado, build e quatro projetos de teste: execução `38743221970`.
- Gitleaks 8.30.0 concluiu sem vazamentos na mesma execução.
- O commit de consolidação das evidências também passou nos dois jobs: execução `38743683486`.
- A primeira execução revelou versão padrão indisponível do Gitleaks no Windows; a configuração foi corrigida para versão fixa e scanner Linux, mantendo build/testes no Windows.
- A API do GitHub confirmou proteção da `main`: PR obrigatório, branch atualizada, histórico linear, conversas resolvidas e checks obrigatórios `build-and-test` e `secret-scan`.
- Em `15/10/2026`, a política foi ajustada para fluxo individual: zero aprovações obrigatórias e `require_last_push_approval` desativado. PR e demais proteções permaneceram ativos, inclusive para administradores; auto-merge permaneceu desativado.
- Force push e exclusão da `main` estão desabilitados.

## Resultado

- Fundação compilável, testes de fumaça, repositório, CI, varredura de segredos e proteção de branch validados.
- Nenhuma regra de domínio, API pública ou schema de negócio foi introduzido.

A conclusão desta task não conclui a Sprint 0 nem qualquer gate G0–G9.
