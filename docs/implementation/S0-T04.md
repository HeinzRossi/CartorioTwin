## Riscos

- Token atual do GitHub CLI inválido pode bloquear criação/configuração remota.
- Restore depende de acesso ao NuGet e pode exigir autorização de rede.
- WPF precisa compilar em Windows; validação local e CI usarão agentes Windows.
- Warnings tratados como erros podem revelar incompatibilidades dos templates.
- Proteção de branch e aprovação obrigatória dependem das capacidades da conta GitHub.

## Evidências de execução

- `dotnet restore CartorioTwin.sln`: concluído; 12 projetos restaurados e 12 lock files gerados.
- `dotnet restore CartorioTwin.sln --locked-mode`: concluído.
- `dotnet build CartorioTwin.sln -c Release --no-restore`: concluído em Windows x64; 0 avisos e 0 erros.
- `dotnet test CartorioTwin.sln -c Release --no-build`: quatro assemblies descobertos; 4 testes aprovados, 0 falhas e 0 ignorados.
- `dotnet list src/CartorioTwin.Domain/CartorioTwin.Domain.csproj reference`: nenhuma referência projeto-a-projeto.
- `dotnet list src/CartorioTwin.Domain/CartorioTwin.Domain.csproj package`: nenhum pacote.
- `dotnet --info`: confirmou SDK 10.0.401, host 10.0.12 e Windows Desktop Runtime 10.0.12, mas retornou código 1 ao consultar o Service Control Manager por falta de privilégio. Restore, build e testes não foram afetados.
